How to get into a server

Three steps, in this order. Each one is a row on the first screen.

1. Game data

The client needs your own GTA San Andreas files. Copy them into /storage/emulated/0/GTA/, or let the app download the cache when a link is configured. The row turns green when the files are complete.

2. Server

Pick a server from the list or add one by address. The chosen server is written to SAMP/settings.ini for you, so nothing has to be typed into a file.

3. Play

The button stays disabled until the first two rows are ready. Nothing is faked during loading: the bar shows the phase the engine reports, and if it takes longer than twenty seconds the screen says so.

Gamepad

A controller is recognised when it is plugged in or paired, even while the game is already running. Sticks have a deadzone so the camera does not drift, triggers are read from the analog axes when the pad has them, and buttons are forwarded with the key code Android assigned.

Backup

Settings has Export and Restore. Export writes one zip with settings.ini and your server list. Restore puts both back, which is what makes a new phone a five minute job instead of an evening.

When it breaks

Diagnostics reads the phone: data files, settings, last crash, pads in use. Copy report puts that text on the clipboard, then the same screen opens the Discord room. Paste it there and the report is already the useful part.

What this build does not do

  • No Rockstar assets are shipped. The APK contains only the client, so the data has to come from your install.
  • Server TextDraw is drawn by the engine. This guide page cannot replace a server's HUD.
  • Voice is compiled in but still needs a real device test before it is called working.
